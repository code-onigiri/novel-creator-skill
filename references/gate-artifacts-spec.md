# Gate Artifacts Specification

Every chapter must produce artifacts in the following directory:
- `04_editing/gate_artifacts/<chapter_id>/`

Required Files:
1. `memory_update.md`
2. `consistency_report.md`
3. `style_calibration.md`
4. `copyedit_report.md`
5. `publish_ready.md`
6. `gate_result.json` (auto-generated by the validation script)

Failure Repair Files (generated when gate check fails):
- `repair_plan.md` (generated by `/repair-chapter`)

## Generation & Validation Order
1. `/update-memory` generates `memory_update.md`
2. `/check-consistency` generates `consistency_report.md`
3. `/style-calibration` generates `style_calibration.md`
4. `/copyedit` generates `copyedit_report.md` and `publish_ready.md`
5. `/gate-check` executes the script to write `gate_result.json`
6. When failed, execute `/repair-chapter` to generate `repair_plan.md`

## Pass Criteria
- All required files exist and are non-empty.
- File modification time is not earlier than the chapter file.
- `publish_ready.md` must contain publish keywords (default: publishable/passed/PASS).
- Chapter files must be `03_manuscript/*.md`.
- `02_knowledge_base/` must not contain chapter files (e.g., `Chapter_xx*.md`).
